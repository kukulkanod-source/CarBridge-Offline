# Сборка CarBridge Offline

## Требования

- JDK 17.
- Android SDK Platform 34 и Build Tools, устанавливаемые через Android Studio.
- Интернет для первой загрузки Gradle и зависимостей Google Maven, Maven Central и JitPack.

Откройте корень проекта в Android Studio, выберите Gradle JDK 17 и выполните синхронизацию. Android Studio создаёт локальный `local.properties` с путём к SDK; его не нужно коммитить.

Сборка в Windows из корня проекта:

```powershell
.\gradlew.bat :app:assembleDebug
```

В Linux/macOS:

```sh
chmod +x gradlew
./gradlew :app:assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

## Подпись

Ключ сопровождающего не входит в репозиторий. Локальная debug-сборка подписывается стандартным отладочным ключом вашей среды. Она не сможет обновить установленный APK с другой подписью. Для собственных релизов настройте свою подпись локально и сохраняйте её ключ отдельно от Git.

## Зависимости

Изменённые исходники LibADB Android находятся в `third_party/libadb`, лицензии и сведения об изменениях сохранены рядом. Неизменённый сервер scrcpy v5.0.1 находится в `app/src/main/assets`; его лицензия и происхождение — в `third_party/scrcpy`.

SPAKE2 2.2.1 загружается из JitPack. При недоступности этого сервиса синхронизация зависимостей может завершиться ошибкой; это не ошибка исходников CarBridge.

## Статус публикации

Опубликован снимок исходников версии 0.64 (`0.64-navigation-road-perspective`, versionCode 65). APK собран из рабочего проекта командой `:app:assembleDebug`, подпись проверена и совпадает с предыдущими сборками сопровождающего. Отдельная сборка опубликованного снимка в чистой среде пока не проверялась.

Лицензия на собственный код CarBridge пока не выбрана. Лицензии сторонних компонентов сохраняют действие; публичная доступность репозитория сама по себе не предоставляет лицензию на собственный код проекта.
