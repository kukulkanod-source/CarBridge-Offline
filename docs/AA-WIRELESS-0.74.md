# CarBridge 0.74 — беспроводное подключение через адаптер

## Схема

CarBridge на телефоне → Android Auto по Bluetooth/Wi-Fi → адаптер CarPlay→AA → CarPlay головного устройства.

Это отдельный экспериментальный транспорт с рабочим столом и виджетами CarBridge.
Встроенный Android Auto на ГУ и дополнительное приложение HeadSwap не требуются.
Протокол USB CarLife и добавленный ранее CarbitLink сохраняются.
Совместимость именно с адаптером владельца требует проверки на автомобиле.

## Первый запуск

1. На телефоне подготовить офлайн ADB обычным мастером CarBridge.
2. Вставить адаптер в порт CarPlay автомобиля и открыть CarPlay на ГУ.
3. В настройках Bluetooth телефона выполнить сопряжение с адаптером.
4. Открыть в CarBridge «Через адаптер CarPlay → AA · эксперимент».
5. Разрешить Bluetooth / устройства поблизости (на Android 11–12 также местоположение), включить Wi-Fi.
6. В списке сопряжённых устройств выбрать адаптер. Подтвердить системный запрос подключения к его Wi-Fi, если появится.

Список показывает все сопряжённые устройства: наличие устройства в списке не означает поддержку AA.
IP, порт, SSID и пароль программа получает через Bluetooth-протокол адаптера.
Автоматическое подключение из фонового Bluetooth-приёмника в этой версии не включено.
Перед сменой транспорта остановить действующий сеанс.

Если соединение не получилось, отправить журнал этой попытки. В журнале различаются RFCOMM,
получение Wi-Fi, присоединение к сети, TCP, TLS, список сервисов и согласование видео.
Если адаптер занят другим телефоном или автоматически подключившимся Android Auto,
предварительно освободить это соединение.

## Реализовано и ограничения

- H.264, размер из предложенных адаптером стандартных альбомных режимов: 800×480, 1280×720, 1920×1080.
- Общий виртуальный рабочий стол CarBridge, его окна, панели и виджеты.
- Касания до двух контактов, основные кнопки домой/назад/медиа/ассистент.
- Звук через существующую настройку «Звук через USB», Android 12+, если адаптер согласовал PCM 48 кГц / 16 бит / стерео.
- Название, исполнитель и обложка через AA MediaPlayback, только если адаптер объявил этот сервис. Передача обложки дополнительно зависит от настройки CarBridge и от поддержки адаптера/ГУ.
- Голос Алисы записывается микрофоном телефона; внедрение микрофона ГУ в стороннее приложение не реализовано. Звонки остаются через штатный Bluetooth.
- Навигационные метаданные AA и отдельный видеопоток приборной панели не подключены; карточки навигации внутри CarBridge работают общим механизмом.
- Wi-Fi-сокет привязан только к сети адаптера; весь процесс не переключается на неё. Интернет зависит от доступности мобильных данных и возможностей телефона.
- По выбранному сопряжённому Bluetooth-устройству запоминается первый успешно проверенный TLS-сертификат. Изменившийся сертификат автоматически не принимается.

## Исправления по журналам 10–11 ноября

- После прерывания звука звонком: проверка 500 мс устойчивого MODE_NORMAL, короткие повторы через 1 и 2 секунды в ограниченном окне восстановления вместо обязательного ожидания 10 секунд после первой переходной ошибки.
- Ошибка запуска захвата во время режима звонка не расходует лимит обычных ошибок. Лимит ошибок сохраняется; успешный стабильный захват очищает счётчик. Принудительный PLAY плееру не отправляется.
- Карточка и передача навигационных подсказок выбирают единый источник. Последний открытый навигатор имеет приоритет; краткий разрыв уведомления не переключает подсказки на другой маршрут. Приложения не останавливаются.
- Пустое служебное сообщение Стрелки без текста/подсказок/изображения не показывает новый баннер.
- Записываются изменения состояния медиасессий без названий треков и текста сообщений.
- Эксперимент Алисы предпочитает реально доступную отдельную AssistantActivity; обычное окно Яндекса не считается перезапускаемым голосовым сеансом. Добавлены компонент и номер запуска в диагностике, отдельно отмечается подавление повтора кнопки. Исправление повторного распознавания голоса не подтверждено; отдельный фоновый режим пока не реализован.
- Снижение нагрузки уже работающего кодера при нагреве остаётся отдельной задачей. Сохранение профиля для следующего подключения не выдаётся за изменение текущего кодера.

## Исходники и сборка

Отдельная копия исходников: `work/CarBridge-AA-wireless`, база — 0.73 с сохранённым CarbitLink.
Версия APK: 0.74-aa-wireless-experiment, versionCode 75.
AARE закреплён на коммите 5d932aec4cffda124fe0b42dd5e9ed80de4f007f, см. `third_party/aare/CARBRIDGE-NOTICE.md`.
Gradle запускается на JDK 17; библиотека AARE собирается в Java 8 bytecode.
Для воспроизведения сборки на другом компьютере локальные init-скрипты не нужны: они подключают имеющийся офлайн-кэш и прежний ключ на ноутбуке владельца.
Автотесты не запускались; готовность реального беспроводного соединения проверяется отдельно от компиляции APK.
