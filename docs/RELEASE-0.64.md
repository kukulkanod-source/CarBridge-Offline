# CarBridge Offline 0.64 — дорога к горизонту

- В карточке навигации нарисована сужающаяся к горизонту дорога с краевыми линиями. Движется центральная прерывистая разметка вместо двух рядов боковых штрихов.
- Начало дороги совпадает с границей голубого и серого фона: координата вычисляется из фактической высоты карточки, включая её уменьшенный вариант над плеером. Разметка обрезается по горизонту и не попадает в небо.
- Исходная пиктограмма уведомления размещена в серой зоне перед машиной с перспективным наклоном. Её содержимое и цвета не заменяются собственными стрелками.
- Ширина VW сохранена, высота изображения уменьшена примерно на 20%, чтобы уменьшить впечатление вида сверху. Это преобразование имеющегося изображения, а не новая трёхмерная модель.
- Декоративная анимация по-прежнему не связана со скоростью автомобиля. Период и ограничение частоты кадров сохранены.

Версия: versionCode 65, versionName 0.64-navigation-road-perspective.
