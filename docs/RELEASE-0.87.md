# CarBridge Offline 0.87

## Что нового

- Улучшена обработка повторных касаний CarLife: карта не должна начинать новый жест при повторном сигнале нажатия. Сохранена обработка двухпальцевого жеста и отпускания пальцев.
- Улучшено восстановление картинки CarLife после сброса видеодекодера ГУ. Повторная команда старта запрашивает свежий ключевой кадр, сохраняя виртуальный дисплей и USB-соединение.
- Исправлена запись безопасных параметров сертификата AA в журнал. Алгоритм подключения AA не менялся.

## EasyConnect / CarbitLink в этой сборке

Беспроводное подключение телефона к совместимому приёмнику на ГУ или Android-планшете:

- поиск устройства в общей Wi-Fi-сети и ручной ввод адреса;
- отдельный виртуальный дисплей с приложениями и интерфейсом CarBridge;
- настройка разрешения и DPI, включая профиль 1920×720 / 300 DPI;
- касания, перетаскивания и сохраняемая калибровка по пяти меткам;
- экспериментальный сетевой звук с отдельным переключателем;
- восстановление звука без переподключения видео;
- управление экраном телефона, статусы подключения и отправка журнала.

Откройте приёмник, соедините оба устройства одной сетью, затем выберите **CarbitLink → «Беспроводное · Wi-Fi» → «Найти ГУ» → «Подключить виртуальный дисплей»**.

Интернет для самой трансляции не требуется. USB-подключение CarbitLink пока не реализовано. В этом режиме обрабатывается один контакт; потоковая передача ограничена максимумом 10 кадров/с. Сетевой звук требует Android 12+, звонки остаются по Bluetooth. Физическая кнопка Power на некоторых прошивках может прервать локальный ADB.

**[Полная инструкция EasyConnect / CarbitLink](https://github.com/kukulkanod-source/CarBridge-Offline/blob/main/docs/EASYCONNECT.md)**

Возможности EasyConnect перечислены как состав сборки; они не все появились именно в 0.87.
